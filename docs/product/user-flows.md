# User Flows

## 1. Farmer Booking a Tractor

```
Farmer Login
    ↓
Dashboard → "Find Equipment"
    ↓
Search by: Location, Type, Date, Duration
    ↓
Browse Results (with photos, price, ratings)
    ↓
Select Tractor → View Details
    ↓
Check Availability Calendar
    ↓
Create Booking → Confirm Date/Time/Rate
    ↓
Payment Processing (UPI/Bank/Wallet)
    ↓
Confirmation SMS
    ↓
Work Session Begins
    ↓
Post-Work: Rating & Review
```

## 2. Tractor Owner Accepting a Booking

```
Login → Dashboard
    ↓
View "Incoming Requests"
    ↓
Notification: New booking request
    ↓
Review Request (dates, location, work type)
    ↓
Accept/Decline/Negotiate
    ↓
If Accepted:
    → Farmer notified
    → Calendar updated
    → Work session created
    ↓
On Completion:
    → Mark as Complete
    → View Payment Status
    → Receive Payment
```

## 3. Contractor Bidding on Work

```
Login → Dashboard
    ↓
"Browse Work Requests"
    ↓
Filter by: Location, Type, Budget, Timeline
    ↓
Select Request → Review Details
    ↓
Submit Quote/Proposal
    ↓
Farmer Reviews Bids
    ↓
If Selected:
    → Create Project
    → Assign Team Members
    → Schedule Work
    → Track Progress
    ↓
On Completion:
    → Submit Report
    → Farmer Approval
    → Payment Released
    ↓
Rating & Feedback
```

## 4. Worker Accepting a Job

```
Login → Dashboard
    ↓
"Available Jobs" (filtered by location, skills)
    ↓
Browse Job Listings
    ↓
Apply or Accept Direct Offer
    ↓
If Accepted:
    → Work details confirmed
    → Start date/time set
    ↓
During Work:
    → Log hours (check-in/check-out)
    → Update status
    ↓
On Completion:
    → Confirm work done
    → Receive payment
    ↓
Rate Employer/Project
```

## 5. Supplier Order Processing

```
Customer Browsing
    ↓
Search Products (seeds, fertilizers, etc.)
    ↓
View Product Details (price, quantity, reviews)
    ↓
Add to Cart
    ↓
Checkout → Address Selection/Confirmation
    ↓
Payment Processing
    ↓
Order Confirmation
    ↓
Supplier Notification
    ↓
Supplier Packs & Ships
    ↓
Customer Receives Tracking
    ↓
Delivery Confirmation
    ↓
Post-Delivery Rating
```

## 6. Messaging Flow (Service Negotiation)

```
Farmer initiates message to Tractor Owner
    ↓
"How much for plowing 5 acres?"
    ↓
Tractor Owner responds
    ↓
Back-and-forth negotiation
    ↓
Agreement reached
    ↓
Farmer: "Book for next Saturday"
    ↓
Create Booking from Chat
    ↓
Confirm & Pay
```
